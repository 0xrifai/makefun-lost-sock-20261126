A make.fun entry for **Funniest Lost Sock Status Update**.

## The line

One status update, in the voice of a lost sock that has ended up somewhere it
should not be. No dryer, no dog, no dust bunnies — this sock has moved on and
is now, professionally speaking, a dust rag. It posts like it is updating its
job profile, because that is the only career move left when your pair is gone
and the household has reassigned you.

## Run it

```sh
node main.ts
```

`main.ts` writes the single status update to `/output/entry.txt` (at most 120
characters, plain UTF-8 text).

## Why this angle

The brief asks for a sock, not a person in a sock costume, and for a premise
that feels found rather than assembled. A sock that treats getting lost as a
career change writes exactly the kind of update a tired professional would
post: open to work, willing to relocate, quietly done with feet. The joke
lands in the last few words, where the sock draws its one boundary.
